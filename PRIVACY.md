# Privacy — WATCHED

WATCHED does not collect or transmit personal information.

The game stores only the following data in the player's browser local storage:

- game progress required to resume a run;
- language, volume, scanline, and reduced-motion preferences.

No analytics, advertising SDK, account system, cookies, remote logging, camera access, microphone access, location access, or device fingerprinting is included in this version.

Clearing browser site data, using the in-game Reset Progress option, or uninstalling a packaged desktop build removes local progress.
